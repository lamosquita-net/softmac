Envoltorios, interceptores y GC de FlyWeb (FM.17)

Para el cambio de los bindings de Blink a la API de V8 12.8 (FlyWeb/docs/v8-12.8-blink.md, §4). Hay que servirla por HTTP (herramientas/motor-gc.sh) y arrancar con --js-flags=--expose-gc; si no hay gc(), se fuerza la recolección con mucha basura. Las iframe de otro origen se cargan desde el otro nombre del mismo servidor (127.0.0.1 ↔ localhost).
