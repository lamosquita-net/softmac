## 4. Arreglos de V8 posteriores a la 12.8.374.38 que tocan la API del embedder (MOTOR-6, 13-10)

Pasada por lectura que pidió COORDINACIÓN-5 tras el cuelgue de YouTube (FM.16). Lo que preocupa son los errores de V8 12.8
que Chrome 128 no pisa y Blink 116 sí. Método:
- de V8 `main`, desde el corte de la 12.8 (451b63ed4, 22-07-2024) hasta el 10-10-2026, salen 379 commits sobre la API del
  embedder: microtareas, callbacks de finalización, `TracedReference`/`EmbedderRootsHandler`, `Wrap`/`Unwrap`,
  interceptores, comprobaciones de acceso, contextos separados, *snapshots* y `ValueSerializer`;
- de ellos se miraron los arreglos, comprobando si el parche aplica sobre 12.8.374.38 (si el fallo existe ahí) y si
  Blink 116 + FM.17 sigue ese camino.
