FlyWebUn navegador actual para los Mac que se quedaron en Mojave

FlyWeb es un navegador para Mac Intel con macOS 10.13 High Sierra y 10.14 Mojave. Está basado en Chromium 116 y Brave 1.57, con el bloqueo de anuncios y rastreadores de Brave, pero sin ninguno de sus servicios: ni estadísticas, ni recompensas, ni cartera de criptomonedas, ni noticias. Las listas de bloqueo y las actualizaciones de seguridad llegan desde un servidor propio en la UE.

Cómo instalarlo

  1. Abre el archivo FlyWeb-1.3.dmg descargado.
  2. Arrastra FlyWeb a la carpeta Aplicaciones.
  3. Ábrelo desde Aplicaciones. La primera vez, macOS te pedirá permiso para guardar la clave de FlyWeb en el llavero: pulsa «Permitir siempre».

Notas de la versión 1.3

  • Motor de nivel Chrome 119. El motor de JavaScript (V8) pasa a ser el de Chrome 119 y FlyWeb se presenta a las webs como Chrome 119. Funciones web nuevas: los selectores :user-valid y :user-invalid para formularios, clip-path con cajas de referencia y con rect() y xywh(), y Promise.withResolvers de serie.
  • Las líneas base del texto en los <canvas> se leen de la propia fuente, como en Chrome.
  • Seguridad: parches posteriores portados al nuevo motor de JavaScript, entre ellos uno para WebAssembly que este motor necesita; el compilador Maglev sigue apagado.

Si tienes FlyWeb 1.0, instala esta versión a mano una vez: la 1.0 no puede actualizarse sola.

Privacidad

FlyWeb no envía estadísticas de uso, informes de fallos ni datos de navegación a nadie. Todo lo que el navegador necesita lo pide a nuestro servidor, que no guarda tu dirección IP. Los detalles, en la página de privacidad.
